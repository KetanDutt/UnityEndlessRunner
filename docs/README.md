# Documentation

Welcome to the Unity Endless Runner documentation. These documents describe how
the project works, what it does, what changed in this improvement pass, and where
it could go next.

## Contents

- **[ARCHITECTURE.md](ARCHITECTURE.md)** — how the game boots itself at runtime,
  the flow of a run, and a reference for every C# script in the project.
- **[FEATURES.md](FEATURES.md)** — a walkthrough of the gameplay features and the
  polish systems (movement feel, UI, SFX, VFX).
- **[CHANGELOG.md](CHANGELOG.md)** — the bugs that were found and fixed, and the
  improvements that were made in this pass.
- **[ROADMAP.md](ROADMAP.md)** — suggested future improvements, from quick wins
  to larger features.
